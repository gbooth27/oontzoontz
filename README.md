# OontzOontz

Grug-simple music maker. Make a beat, add a bassline, sing on top, chain it
into a song. No menus, no plugins, no manual.

## Run it

You need Rust 1.99 or newer.

```sh
cargo run --release
```

Name a song file to open it straight away. `songs/dance-punk.oontz` is a
demo: eight scenes of dance-punk (cowbell, pulsing acid bass, one buzzy riff
whose filter opens up as the song goes on). Press **▶ SONG** to hear it all.

```sh
cargo run --release -- songs/dance-punk.oontz
```

## How to use

1. Press **▶ PLAY** (or the space bar). A beat is already there.
2. **Drums:** click squares to turn hits on and off. Drag to paint lots at once.
   Click a drum's name to hear it. **🎲 Surprise me** makes up a beat.
3. **Synths:** pick **Bass**, **Lead** or **Pad**, then pick a **Sound**. Click
   the grid to add a note, drag right to make it longer, click a note to remove
   it. Every row is in the **Key** and **Mood** you picked, so nothing sounds
   wrong. Want every piano key (sharps and flats too)? Pick the **All notes**
   mood. Changing mood keeps your notes where they are, or moves each one to
   the closest note the new mood has. **Arp** plays chords one note at a time;
   **Pump** ducks on the beat like French house.
4. **Chop:** press **📂 Load WAV** and pick any sound file (a drum break, an old
   record…). Drag across the waveform to pick the part you want, and it gets
   cut into 4, 8 or 16 slices. Click the grid to play the slices in any order.
   **▶ In order** plays the part as it was; **🎲 Surprise me** shuffles it.
5. **Voice:** press **🔴 Record**. You hear four clicks, then the loop plays and
   your mic records exactly one loop, then stops by itself. Headphones help.
   Change the speed later and your take stretches to fit, without changing pitch.
6. **Scenes:** each of **A–H** is one section (verse, chorus, drop…) with its
   own beat, notes, takes, chops, length, drum kit, synth sounds and mix
   (volume, mute, echo, pump, arp, brightness). Click a scene to edit it; if
   music is playing it switches when the current loop ends. A new scene starts
   with the sounds and mix of the one you came from. **⧉ Duplicate** copies a
   scene so you can change it up.
7. **Song:** pick a scene and press **➕ Add** to put it in the song row. Click
   a block in the row to take it out. **▶ SONG** plays the row from the start.
8. **💾 Save** keeps everything (voice and chopped sounds too) in one `.oontz` file.
   **⬇ Export** makes a WAV of the song row (or of the current loop if the row
   is empty).

## Sounds

Drum kits: 808, Punch, Bit. Synth sounds:

| Leads, keys & chords | Basses |
| --- | --- |
| Pluck, Beep, Big Lead, Supersaw, Soft Pad, Strings, Choir, Organ, Bell, Dusty Keys, Talkbox, Disco Stab | Acid Bass, Sub Bass, 808 Bass, Squelch, Reese, Wobble, Growl |

Some of these aim at a particular sound. Wobble and Growl are dubstep-style
basses. Talkbox, Squelch and Disco Stab with Pump go for French house. Acid
Bass and the cowbell go for dance-punk. Dusty Keys and the chop track with the
**Dust** knob make an old-record collage sound.

## Keyboard

| Keys | Does |
| --- | --- |
| Space / ⇧ Space | Play or stop the scene / the song |
| 1 – 8 | Pick scene A – H |
| ⌘Z / ⌘⇧Z (Ctrl+Z / Ctrl+Y) | Undo / redo |
| ⌘C ⌘X ⌘V | Copy, cut, paste a scene |
| ⌘D | Duplicate scene |
| ⌘S / ⌘⇧S / ⌘O / ⌘N / ⌘E | Save / save as / open / new / export |

The **⌨ Keys** button in the app lists them too.

## Microphone on macOS

The first time you turn on the mic, macOS asks for permission. If you started
OontzOontz from a terminal, it is the terminal app that needs permission (System
Settings → Privacy & Security → Microphone). If a take comes out silent, check
there.

## Where the sounds come from

There are no sample files. Every drum and synth sound is generated by the code
in `src/drums.rs` and `src/synth.rs`, so they carry no license strings: use
them for anything. You can also load your own WAV onto any drum (📂 button) or
into the chop track, for example public domain samples from
[freesound.org](https://freesound.org) filtered to the CC0 license, or old
recordings that are out of copyright. Chopping someone else's record is
sampling: fine for fun, but clear it before you release anything.

## Code map

| File | What it does |
| --- | --- |
| `src/song.rs` | Song, scenes and their mix, chops, scales, sound list, save/load, dice rolls |
| `src/engine.rs` | Real-time sequencer and mixer: scenes, song mode, chops, take stretching, pump, arp, dust, synced mic recording |
| `src/synth.rs` | Polyphonic synth: unison stacks, vowel filter, drive, wobble, glide, presets |
| `src/drums.rs` | Drum kits made from math |
| `src/history.rs` | Undo and redo |
| `src/dsp.rs` | Filters and small sound helpers |
| `src/audio.rs` | Speaker and mic streams (cpal) |
| `src/files.rs` | WAV import and export |
| `src/app.rs` | The window (egui) |

`cargo test` checks the engine, scenes and song mode, per-scene mixing, chops,
take stretching, synth presets, drums, undo, file round trips (including files
from older versions) and the recording path.
